# SunamoCryptAlgorithms

## Short description

NuGet knihovna SunamoCryptAlgorithms s kryptografickými pomůckami (symetrické a asymetrické šifrování, DataCrypt, CryptHelperAdvanced). Obsahuje testovací projekt a Runner pro spuštění. Součást sbírky balíčků PlatformIndependentNuGetPackages.
